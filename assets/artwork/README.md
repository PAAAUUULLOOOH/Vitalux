# Vitalux artwork

`liquid-chrome.png` is an original generated background created for Vitalux's
Liquid Chrome design. It contains no stock photography, external lettering or
third-party logo. Keep the original full-resolution PNG; runtime Qt scaling is
cached with the scene. The animated identity and instrument contours remain
native vectors, independently of this static background.

root. Third-party component notices remain in `THIRD-PARTY.md` and `licenses/`.
